# GIRE

Grid Intelligence and Resilience Engine

An advisory-first, Rust-based agentic engineering system for electrical distribution operations, developed by Tilil Engineering Group.

## Overview

GIRE provides intelligent, policy-driven analysis and decision support for electrical distribution networks. AI agents operate in a strictly read-only, advisory capacity — they do not have independent authority to operate electrical equipment. All actions require human review and approval.

## Development Roadmap

- Typed domain model and evidence
- Canonical event ingestion and replay
- Versioned feeder topology
- Deterministic electrical analysis
- Bounded agents and policy kernel
